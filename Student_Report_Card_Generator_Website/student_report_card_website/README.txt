STUDENT REPORT CARD GENERATOR — WEBSITE

Files
- index.html: webpage structure
- style.css: page design and responsive layout
- script.js: validation, calculations, report generation and browser storage

How to run
1. Extract the ZIP file.
2. Open the student_report_card_website folder.
3. Double-click index.html. It opens in your browser.
4. Enter student details and marks, then click Generate report card.
5. Use Print report card to print or save the report as a PDF.
6. Use Save report to store the report in this browser.

Project rules used
- Five subjects: Python, Mathematics, Physics, Chemistry and English.
- Each subject is out of 100; total is out of 500.
- Percentage = total marks / 5.
- Grade: 90–100 A+, 80–89 A, 70–79 B, 60–69 C, 50–59 D, below 50 F.
- PASS only when every subject has at least 33 marks; otherwise FAIL.

Important
- Saved reports use the browser's localStorage on this device/browser.
- This is a front-end website; it does not use a server or online database.
- Clearing browser site data may delete saved reports.
- For a real multi-user production system, a secure backend and database would be needed.
